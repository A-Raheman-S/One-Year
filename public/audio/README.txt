Place your voice note audio file in this folder:

Folder: d:\AF\public\audio\
Default expected filename: voice-note.mp3

Supported formats:
- .mp3
- .m4a
- .wav
- .ogg

If you name your file "voice-note.mp3", it will automatically be loaded!
If your file has a different name (e.g. "my-voice.m4a"), open "src/data/siteConfig.ts" and update:
  voiceNoteAudioUrl: "/audio/my-voice.m4a"

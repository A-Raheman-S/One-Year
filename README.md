# Sunset Promise — Anniversary Website

A premium cinematic interactive anniversary storytelling website.

## Live Site

Hosted on GitHub Pages — automatically deploys when you push to `main`.

## Local Development

```bash
npm install
npm run dev
```

## Personalization

Edit these files to customize:
- `src/data/siteConfig.ts` — Names, dates, photos, song
- `src/data/memories.ts` — Story timeline chapters
- `src/data/reasons.ts` — Flip card reasons
- `src/data/promises.ts` — Promise seals

## Voice Note

Place your audio file at: `public/audio/voice-note.mp3`

## Supported audio formats: .mp3, .m4a, .wav, .ogg

## Tech Stack

- React + Vite + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Framer Motion
- Lenis Smooth Scroll
